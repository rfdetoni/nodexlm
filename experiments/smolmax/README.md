# Smolmax native single-row CPU experiment

This is an isolated port of the single-row binary operator scheduling idea from [smolmaxxing at 8d12bb1](https://github.com/hyperionaidev/smolmaxxing/tree/8d12bb17fd389c25f3c6167a5b73f93034d6324f), MIT (see LICENSE). It targets llama.cpp v1.0.0 (b1b770d90d94cad9e9ea5b993bdbc383a522fb28) and Linux/Android ARM64. The patch is **not** automatically applied to r4 or r5; no published runtime, release hash, RPC wire format or APK changes. It avoids changing views, broadcasting, multi-row scheduling and numerical representation. The targeted ARM64 CI checks FP32 ADD/MUL/DIV results with uneven tails, scalar broadcast, short/multi-row and in-place fallback. These checks do not establish FP16/BF16 correctness or performance, Android compatibility, distributed inference or full Smolmax portability. Before integration, test all supported dtypes, Android, existing GGML operator suite, RPC E2E and on-device benchmarks against an unmodified pinned baseline. No GPU or legacy RPC changes.
